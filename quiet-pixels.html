ATCM 2335: Internet Studio I

Quiet Pixels Dream of Falling Apart

An experimental interactive poem exploring digital decay, fragmentation, and the relationship between technology and memory.

Tools: HTML, CSS, JavaScript

Timeline: Summer 2026

Role: Designer & Developer

Project Overview

Quiet Pixels Dream of Falling Apart is an interactive web experience that combines poetry, animation, and creative coding. The project uses pixel-based visuals and glitch effects to represent digital instability and the temporary nature of online spaces.

Design Concept

The project was inspired by the idea that digital environments are not permanent. Images, files, and websites can change, disappear, or become distorted over time. The interactive elements allow users to experience this feeling of digital fragmentation.

Development Process

I created the experience using HTML, CSS, and JavaScript. CSS animations were used to create movement and visual distortion, while JavaScript controlled interactive behaviors and transitions. I focused on creating an experience that felt unpredictable while maintaining a clear visual structure.

Creative Approach

  • Used pixel grids as a visual representation of digital spaces.
  • Created glitch effects to communicate instability and change.
  • Combined poetry and interaction to create an emotional user experience.

Outcome

This project demonstrates how code can be used as a creative medium. By combining design, storytelling, and technology, the final piece explores new ways users can interact with digital art.
