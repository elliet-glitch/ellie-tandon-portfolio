02 / overview ATCM 2335 / Internet Studio I

lost
computer.

An interactive web experience that turns a familiar computer desktop into a space for digital storytelling and exploration.

Lost Computer is built around the idea of a computer that was left behind. Instead of presenting a traditional linear story, the project lets users explore the desktop and discover pieces of the narrative themselves.

The project was created for ATCM 2335: Internet Studio I during Summer 2026.

05 / concept design goals

explore
the unknown.

The goal was to make the interface feel familiar while using it as a creative storytelling environment.

  • Create a desktop interface users can explore.
  • Use files, photos, and notes as storytelling elements.
  • Keep the narrative open to interpretation.
  • Experiment with interaction as a way of communicating information.
06 / process building the experience

interface
as story.

I built the interface from the ground up and used interaction to make the user part of the storytelling process.

I developed clickable desktop icons, pop-up windows, file interactions, photo previews, system messages, and other interface elements.

I also focused on details that would make the environment feel like an older computer system, including the wallpaper, taskbar, window styling, file icons, and typography.

07 / outcome final experience

click.

The finished project combines web design, interaction, and storytelling into an experience that encourages users to explore.

Rather than simply reading a story, users discover information through the interface and decide for themselves what the different digital artifacts might mean.
