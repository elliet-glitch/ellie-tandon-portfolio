ATCM 2335: Internet Studio I

Lost Computer

An interactive web experience that turns a familiar computer desktop into a space for digital storytelling and exploration.

Tools: HTML, CSS, JavaScript

Timeline: Summer 2026

Role: Designer & Developer

View Live Project View Code

Project Overview

Lost Computer is an interactive website built around the idea of a computer that was left behind. Users explore the desktop by opening folders, documents, photos, notes, downloads, and other digital artifacts.

Rather than explaining a complete story, the project leaves small clues throughout the interface and allows users to decide what they mean. The familiar desktop format makes the experience recognizable while creating room for curiosity and discovery.

Design Goals

  • Create a familiar desktop interface that users can explore.
  • Use files, photos, and notes as digital storytelling elements.
  • Keep the narrative simple and open to interpretation.
  • Experiment with interaction as a way of communicating information.

Development Process

I built the interface from scratch using HTML and CSS and used JavaScript to create the interactive elements. I developed clickable desktop icons, pop-up windows, file interactions, photo previews, and system messages to make the website function like a small interactive computer environment.

I also focused on the visual details of an older computer interface, including the desktop wallpaper, taskbar, window styling, file icons, and typography.

Outcome

The finished project combines web design, interaction, and storytelling into an experience that encourages users to explore rather than simply read. The project allowed me to experiment with how familiar digital interfaces can be repurposed as creative environments for storytelling.
